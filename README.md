# 国际象棋 · 微信好友联机对战（H5 网页版）

一个**单文件前端 + 一个 Node 服务器 + 一份共享规则引擎**的国际象棋，朋友在微信里点开链接就能和你实时对战，**无需下载、不用注册**。

- 创建房间 → 把链接/二维码发到微信 → 好友点开自动进房间
- **完整规则**：王车易位、吃过路兵、兵升变（弹窗选子）、将杀/逼和判定、三次重复判和、50 回合判和、子力不足判和
- 服务端权威校验：非法着法一律拒绝，前端无法作弊
- 执黑自动翻转视角（你的子始终在下方）、合法落点提示、上一步高亮、被将军红格警示
- 棋谱（标准 SAN 记谱）、被吃子力统计、悔棋协商、提议和棋、认输、再来一局（交换黑白）
- 落子/吃子/将军音效（Web Audio 程序化合成，无音频文件）、表情互动、断线自动重连
- 房间 10 分钟无人自动回收

> 想先看界面/试操作：打开 `?demo=1` 是可点击试玩的沙盒（本地模拟走子，无需对手）。

## 一、本地运行

```bash
cd chess-h5
npm install        # 安装 ws 依赖
npm start          # 默认 http://localhost:3000
```

浏览器开两个标签页访问 `http://localhost:3000`：一个「创建房间」，另一个输入房间号「加入」，即可两人对下。

## 二、免费部署（Railway，无需信用卡）

1. 把本目录推到你自己的 GitHub 仓库（`node_modules` 已在 `.gitignore`，Railway 会自动 `npm install`）。
2. 打开 [https://railway.com](https://railway.com) → **Login with GitHub** 授权。
3. **New Project → Deploy from GitHub repo** → 选本仓库。
4. Railway 自动识别 Node：构建 `npm install`、启动 `npm start`（端口读 `process.env.PORT`，代码已对接）。
5. 构建完成后 **Settings → Domains → Generate Domain**，得到 `https://chess-h5-production.up.railway.app` 之类的地址。
6. 发到微信，朋友点开即玩。

> **费用说明**：新账号送 $5（30 天）；之后 Free 计划每月白送 $1 额度、$0/月、不绑卡。本服务是小常驻进程，月耗约 $0.8~1.0，基本能一直免费用；若某月超出额度会暂停到次月重置（不会扣费）。
> 备选：Render 免费版也支持（但注册流程可能要求绑卡）；国内轻量云 + 宝塔最稳（`node server.js` 即可）。

## 三、在微信里怎么和朋友玩

1. 部署拿到公网地址后，手机微信打开 → 点「创建房间」→ 自动生成**分享链接 + 二维码**。
2. 点「复制」发到微信群/好友，或直接把二维码截图发过去。
3. 好友点链接（或扫二维码）→ 自动进入同一房间，白方先手开下。
4. 你执白看白方视角，好友执黑自动翻转棋盘。

> 微信打开外部链接偶尔弹「已停止访问该网页」，点「继续访问」即可（微信对未备案域名的通用提示，非程序问题）。

## 四、技术要点

- **规则引擎单份共用**：`public/chess-engine.js` 以 UMD 导出，Node `require` 与浏览器 `<script>` 加载同一份代码，前后端规则**零分歧**。正确性经 **perft(1~4) 标准计数校验**（20 / 400 / 8902 / 197281 全部吻合）。
- **服务端权威**：所有写操作（走子、悔棋、和棋、认输、重开）在服务端校验回合与着法合法性（`Chess.findMove` 在合法着法表里精确匹配），非法一律拒绝。
- **悔棋用快照**：每步走子前压入状态快照栈，同意悔棋即弹出恢复，天然支持任何复杂局面回退。
- **实时同步**：WebSocket 与 HTTP 同端口；断线自动重连并 `join` 回原座位（按离线前颜色入座）。
- **内存态房间**：单实例、重启即清空（免费套餐够用；需持久化可换 Redis/数据库）。

### 文件结构
```
chess-h5/
├── server.js                 # Node 服务：静态托管 + WebSocket 房间管理 + 权威校验
├── package.json              # 依赖 ws，npm start
├── public/
│   ├── chess-engine.js       # 规则引擎（UMD，前后端共用）：走法生成/合法性/将杀/记谱
│   └── index.html            # 全部前端：首页 + canvas 棋盘 + 音效 + 分享，单文件自包含
└── README.md
```

### 可调项
- 房间回收时间：`server.js` 顶部 `ROOM_TTL`（默认 10 分钟）。
- 棋盘配色：`index.html` CSS 变量 `--light` / `--dark`。
- 音效开关：游戏页右上角 🔊/🔇 按钮（运行时切换）。
